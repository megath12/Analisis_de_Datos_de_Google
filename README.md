📊 Google Data Analytics — Curso de Análisis de Datos

Este repositorio contiene mis apuntes, ejercicios y proyectos desarrollados durante el Certificado Profesional de Análisis de Datos de Google (Coursera).
El objetivo de este curso es adquirir una formación sólida en el proceso completo de análisis de datos, 
desde la limpieza y transformación de información hasta la visualización y comunicación de resultados.

A lo largo del programa se aplican herramientas y lenguajes clave en la industria, como SQL, R, Excel y Tableau, 
con enfoque en el pensamiento analítico, la toma de decisiones basada en datos y las mejores prácticas profesionales.

Este repositorio sirve como registro de progreso, documentación técnica y portafolio de proyectos relacionados con el análisis de datos.
